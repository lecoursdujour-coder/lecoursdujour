# Le cours du jour

Dépôt partagé du projet **« Le cours du jour »** — contenu financier créé à deux
(gestion de patrimoine + gestion d'actif).

## Contenu
- `CONNAISSANCES_short-form.md` — base de connaissances
- `INSTRUCTIONS_PROJET.md` — instructions et cadrage du projet

## Travailler à deux (les 2 réflexes)
1. **Avant de commencer** : récupérer les dernières modifs (« Pull » dans GitHub Desktop).
2. **Après avoir travaillé** : « Commit » (avec un petit message) puis « Push ».

⚠️ Éviter de modifier le *même* fichier en même temps tous les deux, pour ne pas
créer de conflit. Se répartir les fichiers ou se prévenir.
